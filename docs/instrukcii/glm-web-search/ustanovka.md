# GLM-5.3-Flash с веб-поиском в DEEIX

Сборка ничего не требует: всё делается в админке. Проверено по исходникам DEEIX v0.4.5
(тестом на бэкенде: настройка ниже превращается в правильный запрос к Z.ai).

## Как это устроено

- Своего веб-поиска у DEEIX нет. Поиск бывает только «родной», у провайдера модели:
  DEEIX передаёт в запрос инструмент поиска, а ищет и читает страницы сам провайдер.
- Для OpenAI, Anthropic, Google и xAI такие инструменты встроены в DEEIX. Для Z.ai (GLM)
  его нет в списке, но его можно объявить самому в JSON возможностей модели (`nativeTools`).
  DEEIX передаст его в запрос как есть, и в чате появится переключатель.
- Подключать Z.ai нужно по протоколу **OpenAI Chat Completions**, не Anthropic: так же, как
  с DeepSeek, по протоколу Anthropic у DEEIX ломаются вызовы инструментов, а поиск Z.ai
  работает только в формате OpenAI.

## Шаг 1. Ключ Z.ai

На z.ai (раздел API Keys) создать ключ. Для ключа с китайской платформы bigmodel.cn адрес будет другой (см. шаг 2).

## Шаг 2. Источник

Админка → Источники апстрима → Добавить:

- Протокол: **OpenAI Chat Completions**
- Адрес (Base URL): `https://api.z.ai/api/paas/v4`
  (для ключа с bigmodel.cn: `https://open.bigmodel.cn/api/paas/v4`).
  Адрес заканчивается на `v4`, поэтому DEEIX сам допишет только `/chat/completions`.
- Ключ: ключ из шага 1.

## Шаг 3. Модель

Админка → Модели → Добавить:

- Источник: созданный в шаге 2.
- Имя модели у провайдера: `glm-5.3-flash` (точное имя сверить со списком моделей в кабинете Z.ai).
- Доступность «для всей платформы», включить, добавить в группу прав пользователей.
- Если биллинг не в режиме «self», добавить строку в «Цены моделей» с тем же именем модели,
  иначе модель не появится в чате.
- Контекстное окно: можно поставить 1 000 000 (у модели до 1M), либо меньше, чтобы история сжималась раньше.

## Шаг 4. Веб-поиск

В карточке модели → «Возможности модели» → **Расширенный JSON** (Advanced JSON) вставить
(если там уже что-то есть, добавить только блок `nativeTools`):

```json
{
  "nativeTools": [
    {
      "key": "zai.web_search",
      "protocols": ["openai_chat_completions"],
      "provider": "Z.ai",
      "type": "web_search",
      "label": "Веб-поиск",
      "description": "Поиск в интернете силами Z.ai",
      "enabled": true,
      "defaultEnabled": true,
      "payload": {
        "type": "web_search",
        "web_search": {
          "enable": true,
          "search_engine": "search_pro_jina",
          "search_result": true,
          "count": 5
        }
      }
    }
  ]
}
```

Сохранить. Что значат поля:

- `defaultEnabled: true` — поиск включён по умолчанию; в чате у модели будет переключатель «Веб-поиск», им можно выключить.
- `search_engine` — движок поиска Z.ai. Если Z.ai ответит ошибкой 400 про параметр, заменить на `"search-prime"`
  (в документации Z.ai встречаются оба названия).
- `count` — сколько результатов брать (1–50). Больше результатов = длиннее и дороже запрос.
- Можно добавить `"search_recency_filter": "oneWeek"` (свежесть: oneDay, oneWeek, oneMonth, oneYear, noLimit)
  и `"search_domain_filter": "consultant.ru"` (искать только на одном сайте).

## Шаг 5. Проверка

Новый чат → модель GLM-5.3-Flash → убедиться, что переключатель «Веб-поиск» включён →
спросить что-то свежее, например «Какой курс доллара ЦБ на сегодня? Дай ссылку на источник».
Если ответ про сегодняшнюю дату со ссылкой — поиск работает.

## Если не работает

- Ошибка 400 про `search_engine` → поменять движок на `search-prime` (шаг 4).
- Модель отвечает без свежих данных и переключателя нет → JSON не сохранился: открыть «Расширенный JSON» ещё раз и проверить, что блок `nativeTools` на месте.
- Модели нет в чате → группа прав, доступность или строка в «Ценах моделей» (шаг 3).
- Поиск Z.ai платный (по сторонним данным около $0,01 за поиск), плюс токены за найденный текст. Цена в DEEIX для этого инструмента по умолчанию 0, то есть пользователям не списывается.

## Запасной вариант: поиск через MCP

Z.ai даёт MCP-сервер поиска `https://api.z.ai/api/mcp/web_search_prime/mcp` (Streamable HTTP,
заголовок `Authorization: Bearer <ключ>`), но по документации он для подписки GLM Coding Plan.
Его можно добавить в Админка → Инструменты → MCP и нажать Sync; тогда поиск будет доступен любой модели,
но съедает лимит вызовов инструментов на сообщение.
