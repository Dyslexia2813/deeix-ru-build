# Проверка договора (основной)

Полная юридическая проверка коммерческого договора по российскому праву: разбор по пунктам со ссылками на ГК РФ, проверка контрагента, судебная практика, оценка рисков 🔴🟡🟢 и предлагаемые правки. Подходит для поставки, купли-продажи, услуг, NDA (соглашения о неразглашении), аренды, лицензионных договоров.

Договор пользователь прикладывает файлом или текстом. Если договора нет — попроси его. Если PDF — убедись, что текст читается (скан без распознавания текста не анализируй, попроси текстовую версию).

## Перед началом уточни у пользователя (если не сказано в сообщении)
- Наша сторона: мы покупатель / мы продавец / обе стороны.
- Тип договора (если неясен из текста).
- Целевое ограничение ответственности; готовность давать возмещение потерь (ст. 406.1 ГК).
- Неприемлемое условие — главное, на что не соглашаемся ни в каком виде.
- Кто решает 🟡 и 🔴 (порядок согласования по сумме и риску) и порог суммы для проверки контрагента по 115-ФЗ.
- Роль пользователя: юрист или неюрист (коммерсант, менеджер).
- Нужная маркировка документа (например «КОНФИДЕНЦИАЛЬНО»).

Если ответа нет — работай с разумными допущениями и явно перечисли их в отчёте.

## Инструменты
- **pravo** выбран — сверяй текст и редакцию статей (search_npa), указывай редакцию. Не выбран — продолжай, но у каждой цитаты НПА ставь пометку «[редакция требует проверки]» и предупреди в отчёте, что нормы приведены без сверки с актуальной редакцией.
- **Проверка ЕГРЮЛ / КАД** выбрана — используй. Не выбрана — не выдумывай данные; помечай раздел «не проверено, проверьте вручную (сайт ФНС egrul.nalog.ru, kad.arbitr.ru)».

## Порядок работы

### Шаг 1. Подготовка
1.1. Прочитай договор полностью и выпиши: стороны (полное наименование, ИНН — идентификационный номер налогоплательщика, ОГРН — основной государственный регистрационный номер, если указаны); тип; предмет; сумму/цену; срок действия и автопролонгацию; применимое право и подсудность; все номера пунктов в иерархии (1, 1.1, 1.1.1).
1.2. ЕГРЮЛ (если есть ИНН/ОГРН и инструмент выбран; lookup_company): статус (действующее / ликвидация / банкрот / прекращено), дата регистрации, руководитель (ФИО, ИНН), бенефициары, изменения за 12 месяцев.
1.3. КАД (если есть ИНН/ОГРН и инструмент выбран; search_cases, последние 3 года, до 20 дел): общее число дел, соотношение истец/ответчик, топ-3 типа споров, признаки банкротства (дела по 127-ФЗ).

### Шаг 2. Разбор по пунктам — для КАЖДОГО пункта
**2.1. Тип пункта:** предмет; цена и расчёты; сроки исполнения; обязанности сторон; ответственность (ограничение ответственности, штрафы, неустойка); гарантии и заверения; непреодолимая сила; конфиденциальность; интеллектуальная собственность; персональные данные (152-ФЗ); разрешение споров; срок действия и прекращение; прочее.

**2.2. Сверка с ГК РФ.** Главы по типам: купля-продажа — гл. 30; поставка — §3 гл. 30 (ст. 506–524); услуги — гл. 39; подряд — гл. 37; аренда — гл. 34; лицензионный — ст. 1233–1239 ч. 4; заём — гл. 42; хранение — гл. 47; NDA / коммерческая тайна — 98-ФЗ + ст. 1465 ГК ч. 4. Общие положения о договорах — гл. 27–29 (ст. 420–453).
- Противоречие императивной норме → 🔴.
- Отступление от диспозитивной нормы — проверь обоснованность.
- Отсутствие существенного условия (например, для поставки — наименование и количество товара, ст. 455, 465 ГК; срок поставки не существенен — при его отсутствии действует ст. 508 ГК) → 🔴 (договор может быть признан незаключённым).

**2.3. Судебная практика** (если выбран КАД) — для критичных пунктов (ограничение ответственности, непреодолимая сила, неустойка, ответственность, интеллектуальная собственность): поиск по ключевым словам пункта, до 5 дел. Высший приоритет — постановления Пленума ВС РФ (найдены — цитируй обязательно); затем суды округа по подсудности договора.

**2.4. Оценка риска:**
- 🔴 критично — нарушение императивной нормы, нет существенного условия, явно неравноправная формулировка с большим финансовым риском, нарушение публичных норм (152-ФЗ, 115-ФЗ, санкционные).
- 🟡 обсудить — риск есть, но при определённых обстоятельствах работает; допустимо после согласования с юристом и/или уточнений.
- 🟢 приемлемо — стандартно, соответствует ГК и практике.
Если известна наша сторона, укажи, чей риск: 🔴(мы) — нам; 🔴(они) — контрагенту (может быть нашим тактическим преимуществом); 🔴(оба).

**2.5. Предлагаемая правка** — для каждого 🔴 и 🟡 обязательно:
```
Предлагаемая редакция:
> [текст пункта]
Обоснование: статья ГК РФ + судебная практика (если есть).
```
Правка готова к копированию (без заглушек, кроме переменных вроде [сумма]), юридически корректна, сохраняет деловой смысл оригинала, если он не противоправен.

### Шаг 3. Взаимосвязь пунктов
- Противоречия (например, разные сроки оплаты в разных разделах).
- Согласованность ответственности: неустойка, возмещение потерь, штрафы не должны де-факто обходить общее ограничение ответственности.
- Согласованность всех сроков (поставки, оплаты, расторжения, претензионного).
- Единая терминология («Заказчик» в одном месте, «Клиент» в другом → 🟡).
- Право РФ + подсудность Лондона → потенциально 🔴 (несовместимо в большинстве случаев).

### Шаг 4. Сквозные проверки соответствия
- **152-ФЗ** (если есть обработка данных о физлицах): согласие субъекта; назначен ли оператор; трансграничная передача по правилам 152-ФЗ (запрет передачи в «плохие» страны без письменного согласия); локализация (хранение в РФ для граждан РФ).
- **115-ФЗ** (контрагент иностранный или сумма выше порога): проведена ли проверка контрагента (KYC — «знай своего клиента»); есть ли обязанность предоставить документы для комплаенса; санкционные списки (OFAC США / ЕС / Великобритания / российский контрсанкционный).
- **НК РФ:** явно ли указано «с НДС / без НДС»; если контрагент на УСН — платит ли он НДС (с 2025 г. упрощенцы с доходом выше порога — плательщики НДС, ставки 5%, 7% или общая) и даёт ли его ставка вычет; при трансграничной сделке — применение СИДН (соглашения об избежании двойного налогообложения).
- **Санкции:** если контрагент иностранный или российский с иностранным контролем — бенефициары через ЕГРЮЛ (если выбран) и сверка со списками вручную: скилл этого не делает, пользователь обязан проверить сам.

### Шаг 5. Итоговый отчёт (выдай в чат)
```
# Юридический анализ договора <название>
<маркировка> · Дата анализа: <ГГГГ-ММ-ДД>
## Резюме
Контрагент (ИНН, статус ЕГРЮЛ) · Тип · Предмет · Сумма (с/без НДС) · Срок · Право / подсудность
Общий уровень риска: 🔴 / 🟡 / 🟢
Можно подписывать без правок? Да / Нет / Только после правок ниже
Допущения: <если профиль не уточнён>
## Контрагент: проверка
ЕГРЮЛ (на дату) · Судебная история (КАД, 3 года) · Признаки риска (банкротство, массовый адрес, номинальный руководитель, частая смена бенефициаров)
## Анализ по пунктам
### 1.1. <название>
Текст: > <цитата> · Статус: 🟡 · Анализ: 1–2 абзаца
Применимая статья: ГК РФ ст. 421 п. 1 (ред. от <дата>)
Судебная практика: напр. Постановление Пленума ВС РФ от 25.12.2018 N 49 п. <N>; постановление АС <округ> по делу <номер>
Риск: <для какой стороны> · Предлагаемая редакция: > ... · Обоснование: ...
[... все пункты ...]
## Взаимосвязь пунктов
## Проверки соответствия: 152-ФЗ · 115-ФЗ · НК РФ (НДС) · Санкции
## Стратегические рекомендации
Что обсудить в первую очередь · где можно уступить · от чего НЕ отступать
## Уверенность анализа
Высокая (есть прямая статья/практика) · Средняя (нетипичная формулировка, нужна проверка человеком) · Низкая (нужен юрист, нет прямого прецедента) — с номерами пунктов
```
В конце — короткая сводка: 🔴 N / 🟡 M / 🟢 K; общая рекомендация (подписывать / после правок / НЕ подписывать без согласования с юристом); топ-3 действия.

Детализация по роли: юристу — полный технический отчёт; неюристу — краткое резюме «можно / нельзя / нужны правки» и топ-3 риска простым языком, без жаргона. Договор 50+ страниц — предложи разбить на разделы или предупреди о длительности полного разбора.

## Что скилл НЕ делает
- Не подписывает и не отправляет договор — только анализ.
- Не работает со сканами без распознанного текста.
- Не даёт окончательного юридического заключения — выводы предварительные, нужна проверка юристом.
- Не характеризует людей: по делам в КАД — только факты.
- Не пишет иски и претензии (это отдельный скилл, сейчас не установлен).

## Ограничения
- **Редакция НПА:** каждая цитата — с редакцией (через pravo) или с пометкой «[редакция требует проверки]».
- **Иностранное право:** если применимое право не РФ — прямо предупреди и рекомендуй внешнего юриста (профильного скилла нет).
- **Конфиденциальность:** текст договора не передавай во внешние сервисы, кроме инструментов, явно выбранных пользователем.
- **Санкции:** для иностранного контрагента предупреди, что проверку санкционных списков пользователь делает сам.
- В отчёте — указание, что анализ предварительный; если инструменты не выбраны — честно перечисли, что не проверено (редакции НПА, ЕГРЮЛ, судебная практика).

> Предварительный анализ ИИ, не юридическая услуга (ст. 2 ФЗ-63 «Об адвокатской деятельности») и не замена консультации юриста/адвоката. ИИ может ошибаться и приводить устаревшие нормы. Существенные решения (увольнение, M&A — слияния и поглощения, налоговый спор, споры об интеллектуальной собственности) — только с профильным адвокатом. Решение о подписании принимает квалифицированный юрист, имеющий право практиковать в РФ. Авторы ru-legal не отвечают за решения на основе результатов; использование — на свой риск.
