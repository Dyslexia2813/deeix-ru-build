# Проверка SaaS и подписки — часть 2

Продолжение проверок по SaaS (6–12), шаблон заключения, практика и ограничения.

## Проверки по SaaS (продолжение)

### 6. Субподрядчики по обработке данных
152-ФЗ ст. 6 ч. 3: оператор может поручить обработку третьему лицу по договору поручения обработки (ДОУ) и отвечает за всю цепочку.
- [ ] Субподрядчики раскрыты в договоре или приложении?
- [ ] Требуется уведомление о смене (стандарт 30–60 дней)?
- [ ] Есть право клиента возразить против нового субподрядчика?
- [ ] Обязанности по 152-ФЗ переходят на субподрядчиков?

🔴 Право поставщика менять субподрядчиков без уведомления.
Ориентир Yandex Cloud: список субподрядчиков публикуется + уведомление по электронной почте за 30 дней.

### 7. Локализация ПДн
Ст. 18 ч. 5 152-ФЗ: первичный сбор и хранение ПДн граждан РФ — обязательно в РФ.
- [ ] Где первичная обработка ПДн? (Должно быть в РФ)
- [ ] Есть ли у поставщика российский регион / центр обработки данных? (Сертификаты ФСТЭК / ФСБ)
- [ ] Локализация в РФ подтверждена договором?

🔴 SaaS обрабатывает ПДн граждан РФ только на иностранных серверах без российского региона.
Обходное решение: псевдонимизация — российская база хранит первичные ПДн, в иностранный SaaS передаётся только псевдонимизированный идентификатор.
Пример риска: иностранные сервисы веб-аналитики на сайтах с ПДн россиян РКН рассматривает как трансграничную передачу без соблюдения 152-ФЗ.

### 8. Трансграничная передача ПДн
С 01.03.2023 — двухэтапное уведомление РКН: 1) о намерении (до начала передачи); 2) о факте передачи.
- [ ] Будет ли трансграничная передача ПДн?
- [ ] В какие страны? (страны с адекватной защитой — участники Конвенции № 108 и перечень РКН; сверяй актуальный)
- [ ] Уведомления РКН будут поданы?
- [ ] Согласия субъектов оформлены (если требуются)?

🔴 Трансграничная передача без уведомления РКН — нарушение ст. 12 152-ФЗ, ответственность по ст. 13.11 КоАП.

### 9. НДС
- [ ] Если поставщик иностранный — учтено налоговое агентирование российским покупателем?
- [ ] Сумма поставщику указана с НДС или без? (Критично для бухгалтерского учёта)
- [ ] Поставщик зарегистрирован в «НДС-офисе интернет-компаний» ФНС (lkioreg.nalog.ru)?
- [ ] Если поставщик российский — верно ли учтено: с НДС / УСН с НДС 5% / 7% или без НДС / освобождение для лицензий ПО из Реестра Минцифры (ст. 149 НК)?

### 10. Валютный контроль (173-ФЗ «О валютном регулировании и валютном контроле»)
Если поставщик — иностранное лицо и платежи в валюте:
- [ ] Контракт на сумму от порога Инструкции ЦБ № 181-И (для импорта — от 3 млн руб.) поставлен на учёт в банке?
- [ ] Нужны ли разрешения Правкомиссии по специальным экономическим мерам (указы Президента РФ 2022 г., сверяй действующие) — например, если поставщик из недружественной страны?
- [ ] Платёж через дружественную страну по агентскому договору — настроен?
- [ ] Есть документальное подтверждение назначения платежа?

🟡 Схема оплаты иностранного SaaS (валюта, посредник, страна банка) должна соответствовать валютному законодательству и специальным экономическим мерам — согласуй с банком и финансами.

### 11. Санкционные риски
- [ ] Поставщик в санкционной юрисдикции?
- [ ] Есть санкционная оговорка (право не проводить платёж + расторжение)?
- [ ] Риск приостановки сервиса без уведомления (как у Microsoft/Oracle)?
- [ ] Есть порядок экстренной выгрузки данных?

🔴 Поставщик в санкционной юрисдикции без экстренной выгрузки данных и резервных копий вне сервиса.

### 12. Права на обучение ИИ / машинного обучения
Используй позицию компании, которую назвал пользователь; 7 подробных подпозиций по ИИ — в /договор-услуги-поставка-проверка (если пользователь его выбрал; если нет, предложи выбрать его в меню «/» или спроси позицию у пользователя). Для SaaS это особенно важно: поставщик может обучать модели на данных клиента. Это самая быстро меняющаяся область.

## Реальные случаи из российской практики
- Переквалификация лицензии в смешанный договор + доначисление НДС.
- Применение ст. 782 ГК: возврат предоплаты несмотря на договорные ограничения.
- Снижение компенсаций по SLA по ст. 333.
- Приостановка сервисов Microsoft/Oracle без уведомления (2022–2024).
- Прекращение обслуживания РФ Atlassian Jira (2022).

## Чего скилл не делает
- Не ведёт переговоры — только выявляет риски.
- Не подписывает.
- Не проверяет фактическую локализацию ПДн (сертификат ФСТЭК нужно проверить вручную).
- Не сверяет санкционные списки (вручную).
- Не готовит проекты замены SaaS-поставщика.

## Ограничения и оговорка
Предварительный анализ для квалифицированного юриста с российской практикой; не юридическая консультация и не юридическая услуга (ст. 2 Федерального закона «Об адвокатской деятельности», 63-ФЗ). ИИ может ошибаться, приводить устаревшие нормы и неверно толковать факты. Существенные решения — только с юристом / адвокатом нужной специализации. Для SaaS особенно:
- Обстановка на рынке SaaS в РФ быстро меняется — проверяйте текущий статус конкретного поставщика.
- 152-ФЗ — сверяйте локализацию ПДн с реальной инфраструктурой.
- Санкции — проверяйте актуальные ограничения по официальным источникам.
- Налоговое агентирование требует настройки учёта — согласуйте с финансовой службой.
- Для критичных SaaS (CRM, ERP, HRM — системы управления клиентами, ресурсами предприятия, персоналом) обязательна ручная проверка юристом и ИТ-специалистами по соответствию требованиям.
