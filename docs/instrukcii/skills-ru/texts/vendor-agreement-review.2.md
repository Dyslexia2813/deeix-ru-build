# Проверка договора услуг, подряда, поставки — часть 2

## Категории проверок (продолжение)

**10. Персональные данные (152-ФЗ).** Если исполнитель обрабатывает ПДн заказчика:
- [ ] Поручение на обработку ПДн есть (ст. 6 ч. 3 152-ФЗ)?
- [ ] Перечень ПДн, цель, действия указаны?
- [ ] Конфиденциальность обеспечена (ст. 7)?
- [ ] Требования ст. 18 и 18.1 (локализация) учтены?
- [ ] Обязанность обеспечить безопасность (ст. 19) возложена на исполнителя?
- [ ] Трансграничная передача ПДн — уведомление РКН (ст. 12)?

С 30.05.2025 (ФЗ-420) штрафы значительно увеличены; оператор отвечает за обработчика.

**11. Налоговые риски.**
- **НДС:** «с НДС / без НДС / УСН» указано **явно**? Исполнитель на УСН — с 2025 г. может быть плательщиком НДС (ставки 5% и 7% без вычета у него или общая); заказчик получает вычет по выставленному НДС — проверь, какую ставку применяет исполнитель.
- **Исполнитель-нерезидент:** заказчик — **налоговый агент** (ст. 161 НК — НДС, ст. 310 НК — налог на прибыль).
- **ТЦО:** контролируемые сделки — по ст. 105.14 НК (взаимозависимые лица, внешнеторговые сделки с отдельными товарами, офшорные юрисдикции); пороги сверяй по действующей редакции.
- **Дробление с ИП:** исполнитель — ИП с признаками трудовых отношений? Доначисление НДФЛ + взносы + штраф 40%.

**12. Санкции.** Если исполнитель — иностранное лицо или российская компания с иностранным контролем:
- [ ] Ответные специальные экономические меры (указы Президента РФ 2022 г. — сверяй действующие) учтены?
- [ ] Санкционная оговорка есть (право не проводить платёж + расторжение)?
- [ ] Платежи иностранцам — разрешение ПКО / Правительственной комиссии?
- [ ] Контрагент проверен по санкционным спискам? Автоматической проверки нет — только вручную.

**13. Коммерческая тайна / конфиденциальность.** Режим КТ по 98-ФЗ ст. 10 — см. /договор-nda-проверка (если выбран; если нет, предложи выбрать его в меню «/»). Если конфиденциальность — пункт договора, а не отдельное NDA (соглашение о неразглашении): перечень конфиденциальной информации конкретный? срок действия после прекращения договора? стандартные исключения? Если информация действительно критична — рекомендуй отдельное NDA с настоящим режимом КТ.

## Проверка контрагента
Если в сообщении выбран инструмент проверки ЕГРЮЛ / КАД — используй (данные ЕГРЮЛ, судебная история). Если нет — не выдумывай данные, пометь раздел «не проверено, проверьте вручную (сайт ФНС egrul.nalog.ru, kad.arbitr.ru)».

## Ориентиры из практики РФ
Реквизиты конкретных дел перед использованием в документе для внешнего адресата сверяй по kad.arbitr.ru — ниже устойчивые позиции судов, не разбор отдельных дел.
- **Снижение неустойки (ст. 333 ГК):** суд вправе снизить при явной несоразмерности; между коммерческими организациями — только по заявлению должника, мотивированно (п. 1 ст. 333, п. 69–81 ПП ВС РФ от 24.03.2016 № 7). Ставка сама по себе (например, 0,1% в день) несоразмерности не образует. Ниже ставки по ст. 395 ГК между предпринимателями по общему правилу не снижают (п. 72 того же ПП).
- **Односторонний отказ:** ст. 450.1 ГК — уведомлением, без суда; услуги — ст. 782 (обе стороны), подряд — ст. 717 (заказчик); п. 14 ПП ВС РФ от 22.11.2016 № 54.
- **Незаключённый подряд (массовая практика АС МО / АС ПО):** нет сроков (ст. 708) = незаключён; исполнитель — на неосновательное обогащение, теряет договорную неустойку.
- **Споры об ИС:** частый спор — заказчик оплатил разработку, а исполнитель не передаёт исходный код; для ПО, созданного по заказу, право по умолчанию у заказчика (ст. 1296 ГК), но передачу кода и документации лучше прописать прямо.
- **Санкционный форс-мажор (АС МО / АС СПб, 2022–2023):** массовые отказы — санкции предсказуемы для договоров после 02.2022.
- **Переквалификация ИП в трудовые (ФНС, 2023–2025):** регулярность, единственный заказчик, нет своей инфраструктуры. Доначисления + штраф 40%.

## Особенности контрагентов
- **Крупные компании / госкорпорации:** настаивают на своих типовых формах — договаривайся в начале, потом не изменишь.
- **Госконтракты (44-ФЗ / 223-ФЗ):** особые процедуры — отдельный скилл проверки тендерных договоров, сейчас не установлен.
- **Иностранные из недружественных стран:** авто-пометка: санкции, валютный контроль, ограничения по применимому праву.
- **Стартапы:** часто примут вашу форму — быстрее всего «используем нашу».

## Ограничения: чего скилл не делает
- Не ведёт переговоры — выявляет проблемы и предлагает правки.
- Не подписывает.
- Не принимает решения о рисках — только помечает.
- Не проверяет санкции автоматически (только вручную).
- Не проверяет подписи и полномочия — вне рамок.

**Особо важно:** крупные сделки (> 10 млн руб. или критичные для бизнеса) — проверка юристом обязательна; передача ИС всегда требует внимания юриста (дела 2023–2024 — высокие потери); санкционные ограничения быстро меняются — сверяй перед подписанием; ТЦО в трансграничных сделках — нужен налоговый специалист.

*Это предварительный анализ ИИ для квалифицированного юриста, не юридическая услуга (ст. 2 63-ФЗ «Об адвокатской деятельности») и не замена консультации адвоката. Возможны ошибки и устаревшие нормы. Существенные решения (слияния и поглощения, налоговый спор, споры об ИС, увольнение) — только с профильным адвокатом (ФПА). Используйте на свой риск.*
