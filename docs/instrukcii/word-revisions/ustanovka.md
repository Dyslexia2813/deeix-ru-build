# Установка: правки, примечания, таблицы и номера пунктов Word (PR #23)

PR: https://github.com/Dyslexia2813/deeix-ru-build/pull/23
Сборка: https://github.com/Dyslexia2813/deeix-ru-build/actions/runs/42490614167 (ветка `feat/word-revisions`, 2026-11-08)

Меняется только бэкенд (бинарник `deeix-chat`). Сайт (`out`) и база остаются как есть. В сборке есть всё, что уже стоит на сервере (до PR #21 включительно), плюс новое чтение Word.

## Что изменится
Во вложенных `.docx` и `.doc` модель увидит:
- исправления: `[удалено (Иванов И.И., 01.11.2026 10:15): 30][вставлено (Иванов И.И., 01.11.2026 10:15): 45]`;
- примечания рядом с текстом, к которому они относятся: `[примечание 1 (Петров П.П., 02.11.2026 09:00) к «комиссией»: Оговорить сколько человек…]`, а также ответы и отметку «решено»;
- сноски на своём месте;
- таблицы на своём месте: каждая строка таблицы идёт одной строкой, ячейки разделены ` | `;
- номера пунктов: «4.5.», «а)», «I.».

## Шаг 1. Скачать
1. Дождитесь зелёной галочки у сборки по ссылке выше. Внизу, в разделе Artifacts, скачайте только `deeix-ru-backend` (придёт файл `deeix-ru-backend.zip`).
2. В 1Panel → «Файлы» сначала удалите старый `/opt/deeix-ru/deeix-ru-backend.zip`, потом загрузите новый. Если браузер назвал файл `deeix-ru-backend (1).zip`, переименуйте его в `deeix-ru-backend.zip`.

## Шаг 2. Одна команда в терминале 1Panel
Команда сохраняет текущий бинарник как `deeix-chat-pered-23`, ставит новый и перезапускает контейнер.

```
clear && cd /opt/deeix-chat/DEEIX-Chat/deploy && C="docker compose -f docker-compose.sqlite.yml -f /opt/deeix-ru/compose.override.yml" && $C stop app && cp -a /opt/deeix-ru/deeix-chat /opt/deeix-ru/deeix-chat-pered-23 && unzip -o -q /opt/deeix-ru/deeix-ru-backend.zip -d /opt/deeix-ru && chmod +x /opt/deeix-ru/deeix-chat && echo "новый код: $(grep -c extractDocxMarkupText /opt/deeix-ru/deeix-chat)" && $C up -d --force-recreate app && sleep 10 && curl -s http://127.0.0.1:8080/healthz
```

Должно появиться `новый код: 1` или больше (2 — тоже нормально), а в конце `{"status":"ok",...}`. Если видите `новый код: 0`, значит в zip лежит старый бинарник: скачайте его заново.

## Шаг 3. Проверить
1. **Важно:** договор, который уже загружали раньше, сначала удалите в разделе «Файлы» боковой панели. Текст файла извлекается один раз при загрузке, и если прикрепить тот же файл снова, DEEIX возьмёт старый текст.
2. В новом чате прикрепите договор с исправлениями и спросите: «Перечисли все исправления и примечания в договоре с авторами».
3. Модель должна назвать удалённый и вставленный текст п. 4.5 и примечание про комиссию.

## Откат
```
clear && cd /opt/deeix-chat/DEEIX-Chat/deploy && C="docker compose -f docker-compose.sqlite.yml -f /opt/deeix-ru/compose.override.yml" && $C stop app && cp -a /opt/deeix-ru/deeix-chat-pered-23 /opt/deeix-ru/deeix-chat && $C up -d --force-recreate app
```

## Уборка после проверки
```
clear && rm -f /opt/deeix-ru/deeix-chat-pered-23
```

## Ограничения
- Изменения оформления (жирный шрифт, отступы) не показываются, только изменения текста.
- В `.doc` Word 97–2003 нет ответов на примечания и нет переноса текста. Дата примечания есть только у файлов, сохранённых в Word 2002 и новее.
- Колонтитулы и надписи по-прежнему не читаются.
