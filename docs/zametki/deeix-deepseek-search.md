# deeix-deepseek-search

_Веб-поиск DeepSeek в DEEIX: 3 варианта (Anthropic web_search через nativeTools, MCP-прослойка к Search/Fetch API, Responses API), что рекомендовано._

- 2026-10-24 Kimi спросил про https://api-docs.deepseek.com/api/search/.
- У DeepSeek три пути: (1) серверный web_search на Anthropic-эндпоинте https://api.deepseek.com/anthropic (как в Claude Code); (2) отдельные Search/Fetch API POST https://api.deepseek.com/v1/tools/search и /v1/tools/fetch (query ≤128 симв., count, need_content; ~$0.75/1000, по слухам бесплатно до 2026-11-01); (3) web_search в Responses API, по докам только deepseek-v4-pro.
- DEEIX: встроенный anthropic.web_search_20250305 привязан к протоколу, не к провайдеру, так что для модели DeepSeek на источнике Anthropic Messages его включает nativeTools в JSON возможностей (`{"key":"anthropic.web_search_20250305","protocols":["anthropic_messages"],"enabled":true,"defaultEnabled":true}`). anthropic.go разбирает server_tool_use / web_search_tool_result. По умолчанию DEEIX считает $0.01 за поиск.
