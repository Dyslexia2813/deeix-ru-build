# deeix-glm-web-search

_Как в DEEIX v0.4.5 дать GLM (Z.ai) веб-поиск: свой nativeTools в JSON возможностей модели, протокол OpenAI Chat Completions._

- 2026-10-23 Kimi спросил, как добавить GLM-5.3-Flash с веб-поиском. Инструкция: ../instrukcii/glm-web-search/ustanovka.md.
- У DEEIX нет своего веб-поиска, только «родные» инструменты провайдера (backend/internal/shared/nativetool/catalog.go: OpenAI, Anthropic, Google, xAI). Любой другой провайдерский инструмент объявляется в JSON возможностей модели (`nativeTools` с `payload`), DEEIX передаёт payload как есть и показывает переключатель в чате (`defaultEnabled` — включён по умолчанию).
- Для Z.ai: источник OpenAI Chat Completions, `https://api.z.ai/api/paas/v4`; payload `{"type":"web_search","web_search":{"enable":true,"search_engine":"search_pro_jina","search_result":true,"count":5}}`. Проверено go-тестом на v0.4.5 (nativeProviderToolsFromOption), на живом Z.ai не проверено; движок может быть `search-prime`.
- 2026-10-23 Kimi подтвердил: у GLM-5.3-Flash поиск работает. Для других моделей Z.ai (glm-5.3 и т.п.) тот же источник и тот же JSON. См. [deeix-deepseek-anthropic](deeix-deepseek-anthropic.md), [deeix-model-catalog](deeix-model-catalog.md).
- 2026-10-25 Kimi: у обеих GLM (5.3 и 5.3-Flash) поиск по факту не работает, хотя глобус включён (Default on). По коду DEEIX tools с web_search доходят до запроса; ответное поле `web_search` DEEIX не показывает, отладка запроса видна только у упавших ответов. Дан curl-тест с VPS напрямую в api.z.ai (оба движка), ждём вывод. Из облака api.z.ai недоступен (прокси).
- 2026-10-25 curl-тест с VPS: напрямую Z.ai ищет с обоими движками (search_pro_jina и search-prime, по 5 ссылок), ответ ~1 мин (рассуждение GLM по умолчанию). Значит проблема на стороне DEEIX или в сочетании с MCP-инструментами/стримом. DEEIX не показывает поиск Z.ai в UI (нет источников). Дан второй тест: stream + function-инструмент рядом с web_search; и проверка в чате с MCP вкл/выкл.
- 2026-10-25 ПРИЧИНА: при наличии function-инструментов (pravo) Z.ai встроенный web_search не выполняет (тест: stream+function → 0 поиска, 2 tool_calls; в чате DEEIX только «веб» — свежий ответ). Решение: MCP-сервер zai-search (../instrukcii/glm-web-search/zai_search.py, fastmcp 3.4.8 из /opt/pravo-mcp/venv, Z.ai Web Search API search-prime, 172.19.0.1:8766/mcp, systemd zai-search, ключ /etc/zai-search.env). Инструкция ustanovka-mcp.md. Проверен здесь на имитации API; установку на VPS Kimi пока не подтвердил.
