# deeix-model-catalog

_DEEIX-Chat: от чего зависит, видна ли модель в выборе модели в чате (цены по имени, доступность, группы прав)_

По коду DEEIX-Chat (backend/internal/application/channel/service_model.go, ListActiveModels):
- В чате видна модель, если: статус включён, есть активный источник, доступность «для всей платформы» (public), модель входит в группу прав пользователя (связь по ID).
- Если режим биллинга не «self» (period/usage), модель без строки в «Цены моделей» (таблица billing_model_prices) скрывается. Цена привязана к ИМЕНИ модели (platform_model_name), при переименовании модели не переносится. Отсюда «переименовал модели — пропали из чата» (диагноз 2026-10-17, решение пользователем ещё не подтверждено).
- Display Group влияет только на группировку, не на видимость. Кэш цен 30 с.
- 2026-10-24 «Запись кэша / 1 млн» в «Базовая цена модели»: у DeepSeek и Z.ai (GLM) отдельной платы за запись в кэш нет, ставить = цене «Вход» этой модели (DeepSeek V4 Pro: вход 0,66, чтение кэша 0,022, выход 1,98).
