# deeix-own-ocr

_Своё OCR в DEEIX-RU (2026-11-06) — сайдкар deeix-ocr (Tesseract rus+eng + Go) под встроенный движок «tesseract» апстрима; замеры памяти; в работе._

- 2026-11-06 Kimi попросил своё OCR, чтобы текстовые модели получали картинки и PDF без текста; беречь VPS (709 МБ ОЗУ).
- Апстрим v0.4.6 уже умеет движок `tesseract`: HTTP POST multipart (file, page_ranges, prompt) на `extract:tesseract_ocr_base_url` (по умолч. http://127.0.0.1:8004/ocr), GET /healthz; ответ JSON {rendered_pages, pages:[{page_number,text}]}, 204 = пусто. Готовый deploy/services/tesseract апстрима — Python, ~400 МБ, chi_sim; не берём.
- Апстрим: картинки текущего хода всегда direct_image; у модели без image-модальности → пометка «не поддерживается», OCR-текст не используется — нужен патч бэкенда.
- Замеры (здесь, 4 ядра, OMP_THREAD_LIMIT=1, плотная A4): 150 DPI 87 МБ/5 с, 200 DPI ~105 МБ/5 с, 300 DPI 160 МБ/9 с; pdftoppm 200 DPI ~26 МБ. Внимание: PDF из PIL без resolution= даёт гигантскую страницу (ложные 800 МБ).
- План: контейнер deeix-ocr (debian-slim, tesseract-ocr-rus/eng, poppler-utils, Go-сервер), одна задача за раз, nice/ionice, 200 DPI, ≤30 стр., mem_limit 256m; образ собирает GitHub. Выбор «картинки+PDF или только PDF» — карточка 2026-11-06.
- См. [vps-memory-scan-pdf](vps-memory-scan-pdf.md), [deeix-doc-text](deeix-doc-text.md).
- 2026-11-06 сделано: PR https://github.com/Dyslexia2813/deeix-ru-build/pull/19 (ветка feat/own-ocr): ocr-service/ (Go+Tesseract, база ubuntu:24.04), .github/workflows/ocr-image.yml (артефакт deeix-ocr-image), patches/ocr-text.patch (--no-ocr-text, нужен scan-pdf). Сборки (обе зелёные): образ run 42193379095 (187 МБ, простой 4 МБ под лимитом 300m), бэкенд run 42193393738 (zip 25,4 МБ). PR #19 слит 2026-11-06 (squash 16190ab), стоит на VPS (контейнер deeix-ocr запущен, бинарник новый). Метка для проверки бинарника: grep -c 'Text recognized by OCR'. Поля OCR в админке видны только при включённой галочке — настраивать в два захода. Инструкция ../instrukcii/own-ocr/ustanovka.md. Адрес в админке http://deeix-ocr:8004/ocr, тайм-аут 600.
