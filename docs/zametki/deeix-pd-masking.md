# deeix-pd-masking

_Своя маскировка ПД в DEEIX — прокси deeix-pd-mask + контрол «Маскировка ПД», PR #27 (слит, на VPS); окно «Что увидит модель» — patches/pd-preview.patch, PR #28 (слит 2026-11-14, стоит на VPS)._

- История: обсуждение с 2026-10-22 ([deeix-masking-timeout](deeix-masking-timeout.md)); варианты были: две модели, свой прокси, NER (тяжело для VPS 709 МБ). Выбран свой прокси.
- 2026-11-13 Kimi выбрал вариант 2, кнопка в панели «⋯». Потом — окно «Просмотр перед отправкой» (замаскированный текст, таблица замен, подсветка, предупреждения; без цены — стоимость уже считается, [deeix-effort-cost](deeix-effort-cost.md)). Полный предпросмотр запроса и «Что ушло» не нужны.
- 2026-11-13 сделано (вариант 2): Go-прокси `pd-mask/` в deeix-ru-build, PR https://github.com/Dyslexia2813/deeix-ru-build/pull/27, образ — workflow pd-mask-image.yml (run 43490463025, ~2 МБ ОЗУ). Патча DEEIX нет: кнопка = `controls` в JSON возможностей модели (toggle, on → patch {"deeix_pd_mask":true}), видна в «⋯». Прокси убирает флаг, маскирует (HMAC-метки [FIO_xxxxx], без состояния), возвращает значения в ответ и аргументы инструментов (OpenAI chat + Anthropic, поток). PD_ROUTES имя=хост; базовый URL апстрима: хост → http://deeix-pd-mask:8090/имя. Маршрут `always` — для «Модели для задач/сжатия» (идут без флага). Рассуждения модели остаются с метками.
- Инструкция: ../instrukcii/pd-mask/ustanovka.md. 2026-11-14 установлено на VPS (маршруты ds, kdk=api.kodikrouter.ru, zai; в compose `name: deeix-pd-mask`, иначе deeix-ocr — orphan), в тексте работает; PR #27 слит (squash 4591bde). Минус: прячутся и ФИО известных людей — возможна доработка «список исключений». Следующий шаг по плану — окно просмотра перед отправкой (без цены).
- 2026-11-14 окно просмотра: PR https://github.com/Dyslexia2813/deeix-ru-build/pull/28 (ветка pd-preview). Прокси: POST /preview + правила `deeix_pd_mask_rules {keep,hide}` в запросе (ручные слова → [FIO_]/[PD_], подсказки «похоже на фамилию»/ИНН с плохой суммой). Аддон: patches/pd-preview.patch (кнопка-глаз ScanEye рядом с контролом pd_mask, окно chat-pd-preview.tsx, бэкенд POST /api/v1/pd-mask/preview → DEEIX_PD_MASK_URL, по умолчанию http://deeix-pd-mask:8090), флаг --no-pd-preview. Правила хранятся в параметрах чата, при выключенной маскировке убираются. Инструкция ../instrukcii/pd-preview/ustanovka.md (бэкапы *-pered-28, образ deeix-pd-mask:pered-28).
