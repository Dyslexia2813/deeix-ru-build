# deeix-quote-select

_Кнопка «Цитировать» у выделенного текста в ответе модели — patches/quote-select.patch, PR #34._

- 2026-11-24 Kimi попросил цитирование: выделить кусок ответа модели и ответить или прокомментировать именно его. Выбран простой вариант (без комментариев на полях, как в Word, и без хранения в базе).
- Как сделано (только сайт): при выделении внутри одного `[data-chat-assistant-content]` появляется плавающая кнопка «Цитировать» (`sections/chat-quote-selection.tsx`, `position: fixed`). Мышь — над первой строкой выделения после отпускания кнопки мыши; телефон (`pointer: coarse`) — под выделением, чтобы не перекрывать системное меню. `onMouseDown`/`onPointerDown` с `preventDefault` — нажатие не сбрасывает выделение. Текст передаётся через `hooks/use-chat-quote-select.ts` (модульный список слушателей) в `chat-input.tsx`: дописывается после черновика как `> …` (каждая строка), курсор строкой ниже. Режим ↕ (focus-toggle) снимается. Кнопки нет в режиме выбора сообщений для скриншота.
- Цитата в отправленном сообщении рисуется blockquote (сообщение пользователя идёт через StreamdownRender). Модель получает её обычным текстом Markdown.
- Подписи через `useLocale` (ru/zh/en), json не менялись. Флаг `--no-quote-select`, патч идёт последним (после ui-tags).
- Проверено локально (Playwright 1280 px и Pixel 7): кнопка появляется, цитата встаёт в поле, курсор под ней. Сборка run 45353214024, инструкция: ../instrukcii/quote-select/ustanovka.md (копия out-pered-citatoy). Слить только после «сливай» от Kimi.
