# deeix-tools-not-called

_Модель DEEIX не вызвала выбранные MCP-инструменты: как устроен выбор, почему второй сеанс ни при чём, встроенные промпты-тормоза, проверка по БД._

- 2026-10-27 Kimi: у пользователя pravo 6/6 + deepseek-web-search 2/2 включены, deepseek-v4-pro со скиллом «Проверка договора» не вызвал ни одного инструмента (вход 33 088, кэш 6 400 — один запрос к LLM).
- Выбор инструментов (v0.4.5): хранится в памяти вкладки + localStorage по ключу диалога (use-chat-composer-selection.ts, без события storage), уходит в запросе selectedToolIDs. Другие вкладки/сеансы на отправку не влияют. Сервер молча выкидывает инструмент, если он/сервер неактивен, URL не доверенный, токен не расшифрован (service_mcp_tools.go resolveSelectedToolRuntime); после Sync с переименованием в необновлённой вкладке могут остаться старые ID.
- Встроенные промпты отговаривают от вызовов: MCP «Use tools only for external, realtime, private, or explicitly requested data», контракт скиллов «These skills do not grant permission to … tools». Меняются в админке: Инструменты → «Промпт MCP-инструментов» (mcp_tool_prompt), Диалоги → блок «Библиотека» внизу → вкладка «Навыки» → «Промпт вызова навыков» (chat.skills_prompt; отдельного пункта «Библиотека» в меню админки нет). Пустое = встроенный.
- Признак в ответе: скилл /договор-проверка без инструментов ставит «[редакция требует проверки]».
- Проверка по БД: событие trace с "kind":"tool_guidance" (sourceCount = число переданных инструментов) в chat_run_events по run_id ответа; chat_runs.tool_calls_count. См. [deeix-usage-line](deeix-usage-line.md), [deeix-skills-ru](deeix-skills-ru.md), [deeix-deepseek-search](deeix-deepseek-search.md).
- 2026-10-27 вывод БД: время под ответом = updatedAt (конец), в БД created_at = начало (UTC). Ответ Kimi 22:01:52 МСК, 262 с = run 18:57:30 UTC: инструментов передано 8, вызовов 0 — модель сама не стала вызывать. Мой промежуточный вывод «виновата строка Инструменты» был ошибкой (сравнивал с created_at). Решение: свои тексты в «Промпт MCP-инструментов» и «Промпт вызова навыков» (предложены Kimi 2026-10-27).
- Строка трассы «已提供 N 个 Skill 上下文» (сервер пишет по-китайски, сайт не переводил) переведена в ru-locale.patch (localizeProcessSummary + localizeTraceStages, ключи chat.processTrace.skill.*): PR https://github.com/Dyslexia2813/deeix-ru-build/pull/14, сборка run 40659070898, инструкция ../instrukcii/skill-trace-ru/ustanovka.md. 2026-10-28 Kimi поставил и проверил, PR #14 слит (f9a9507), стоит на VPS.
