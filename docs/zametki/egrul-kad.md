# egrul-kad

_Подключение MCP ЕГРЮЛ (egrul) и КАД (kad) из ru-legal к DEEIX-Chat: что нужно и что проверено._

- egrul-mcp (ru-legal mcps/egrul): нужен ключ API_FNS_KEY с api-fns.ru, бесплатный тариф «СПК-старт» = 800 запросов суммарно. Ключ пользователь вписывает сам, не просить. Ставить как pravo (мост fastmcp stdio→HTTP, systemd, 172.19.0.1, другой порт). На 2026-10-16 решение о регистрации не принято.
- kad-mcp: официального API нет. 2026-10-16 POST на kad.arbitr.ru/Kad/SearchInstances с VPS вернул HTML «Доступ заблокирован»: Но GET главной с VPS = 200 «Картотека арбитражных дел», т.е. IP не забанен; блокируется сам POST поиска. kad-mcp (httpx) не заходит на главную за cookie перед поиском — проверяем POST с cookie jar; если и так блок, нужна JS/wasm-cookie → только настоящий браузер (на 700 МБ не ставить).
- Без них contract-review работает в деградированном режиме (только pravo). См. [deeix-ru](deeix-ru.md), [vps-memory-scan-pdf](vps-memory-scan-pdf.md).
