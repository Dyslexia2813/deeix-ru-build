# preferences

_Как работать с пользователем в проекте DEEIX-RU (команды для VPS, уборка временных файлов)._

- [stated] не оставлять «хвосты» на VPS: временные файлы, клоны, сломанные окружения удалять сразу, как они перестали быть нужны
- [stated] тестовые скрипты для терминала VPS начинать с команды `clear`, чтобы прошлый вывод не мешался
