# vps-memory-scan-pdf

_Причина зависания VPS tap.teamdream.online при отправке PDF-сканов и что уже сделано (swap, лимиты, исправление scan-pdf.patch)._

- 2026-10-15 VPS (709 МБ ОЗУ) завис при отправке двух PDF-сканов. Причина: в scan-pdf.patch `xdraw.BiLinear.Scale` выделял буфер dstW×srcH×32 байт (85–180 МБ на страницу A4), пик ~450 МБ. Надпись «Полный текст» в UI вводила в заблуждение: неизвестный режим `direct_scan` UI показывает как full_context (service_trace.go, default).
- Исправление: PR https://github.com/Dyslexia2813/deeix-ru-build/pull/1 (уменьшение 2×2 + ApproxBiLinear в RGBA, поочерёдная обработка страниц, 20 страниц и 20 МБ на файл, 40 Мпикс). Пик ~137 МБ. Go-прокси из облака теперь работает: бэкенд собирается и тестируется локально.
- На VPS 2026-10-16: swap 2 ГБ в fstab, swappiness 10; в /opt/deeix-ru/compose.override.yml добавлены restart: unless-stopped, mem_limit 320m, memswap_limit 1g (копия .bak). OCR-резерв PDF выключен, движок Built-in.
- 2026-10-16: PR слит, бинарник собран и заменён (старый в /opt/deeix-ru/deeix-chat.prev). Оба PDF отправлены вместе, всё прошло без зависания. GOMEMLIMIT не добавлялся.
- SSH из облака к VPS нет: команды выполняет пользователь в веб-терминале 1Panel, начиная с `clear`. 2026-10-18 Kimi попросил давать команды одним блоком, связанным через `&&`, а не по одной.
- 2026-10-16 SSH закрыт от перебора: /etc/ssh/sshd_config.d/10-no-password.conf — снаружи root только по ключу, пароль разрешён лишь с 127.0.0.1/::1 (так подключается веб-терминал 1Panel, через который работает пользователь). Удалены .bak и deeix-chat.prev; в /opt/deeix-ru остались старые zip и out.bak.
- 2026-10-17 «у других пользователей Ошибка обработки»: Deeix переиспользует загрузку по SHA-256 отдельно у каждого пользователя, а файл в статусе failed повторно не обрабатывается. У кого скан был загружен до патча, тот видел старую ошибку. Исправление в scan-pdf.patch: PR https://github.com/Dyslexia2813/deeix-ru-build/pull/2 (не переиспользовать failed). PR слит, 2026-10-20 пользователь подтвердил, что всё работает. Обход для старых версий: удалить файл в разделе файлов и загрузить заново.
