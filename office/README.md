# deeix-office: файлы Word и Excel по запросу модели

MCP-сервер для DEEIX Chat с двумя инструментами:

- `make_docx` — документ Word: заголовки (уровни 1–3), абзацы с выравниванием, **жирный**, *курсив*, __подчёркнутый__, нумерованные и маркированные списки, таблицы (строка заголовков повторяется на каждой странице, заливка ячеек, ширина колонок), разрыв страницы; шрифт и размер всего документа, поля страницы (по умолчанию 30/15/20/20 мм), номера страниц.
- `make_xlsx` — таблица Excel: несколько листов, жирная закреплённая строка заголовков с фильтром, ширина колонок по тексту, числа как числа, даты (`2026-11-20`, `20.11.2026`), формулы (`=SUM(D2:D10)`), форматы money/percent/date/integer/number/text, заливка ячеек. ИНН и другие длинные номера остаются текстом.

Модель передаёт содержимое в аргументах, сервер собирает файл (только стандартная библиотека Go) и отвечает JSON с полями `url` и `markdown`. Ссылка вида `/api/v1/office-files/<токен>/<имя>` открывается через DEEIX (патч `office-files`), который передаёт запрос сюда, на `GET /files/<токен>/<имя>`.

Токен — 128 случайных бит, по нему файл и отдаётся (без входа в DEEIX). Файлы лежат в томе `deeix-office-data` и удаляются через `OFFICE_TTL_DAYS` дней (по умолчанию 7); если вместе они больше `OFFICE_MAX_MB` (200 МБ), сначала удаляются самые старые.

## Запуск

```
docker compose -f /opt/deeix-ru/compose.office.yml up -d
```

В DEEIX: Админка → Инструменты → MCP-серверы → добавить `http://deeix-office:8095/mcp`, синхронизировать.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Что |
|---|---|---|
| `OFFICE_ADDR` | `:8095` | адрес |
| `OFFICE_DIR` | `/data` | где хранить файлы |
| `OFFICE_TTL_DAYS` | `7` | сколько дней хранить |
| `OFFICE_MAX_MB` | `200` | предел общего размера |
| `OFFICE_LINK_PREFIX` | `/api/v1/office-files` | начало ссылки в ответе |

## Проверка

`go vet ./... && go test ./...`. Workflow `office-image.yml` собирает образ, проверяет его в контейнере с лимитом 64 МБ и выкладывает `deeix-office-image.tar.gz`.
