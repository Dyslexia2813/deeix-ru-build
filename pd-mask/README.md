# deeix-pd-mask: маскировка персональных данных

Небольшой прокси между DEEIX Chat и провайдерами моделей. Когда в чате включён переключатель «Маскировка ПД», прокси до отправки запроса заменяет персональные данные метками вида `[FIO_k3m9q]`, `[INN_ab2cd]`, а в ответе модели и в аргументах вызовов инструментов возвращает настоящие значения. Провайдер и модель видят только метки. Пользователь, база DEEIX и инструменты (например, pravo) видят настоящие данные.

Патч DEEIX не нужен. Переключатель — штатный «контрол модели» DEEIX v0.4.6 (JSON возможностей модели, поле `controls`). Во включённом состоянии он добавляет в тело запроса `"deeix_pd_mask": true`, прокси этот флаг читает и удаляет.

## Что прячется

| Метка | Что | Как находится |
|---|---|---|
| `FIO` | ФИО | «Иванов Иван Иванович» в любом падеже и порядке, «Иванов И.И.», «И.И. Иванов», «Иван Иванович», ЗАГЛАВНЫМИ. Полное ФИО и инициалы одного человека получают одну метку |
| `TEL` | телефон | +7… и 8… в любой записи |
| `EMAIL` | почта | |
| `INN` | ИНН (10 и 12 цифр) | с проверкой контрольной суммы |
| `OGRN` | ОГРН, ОГРНИП | с проверкой контрольной суммы |
| `SNILS` | СНИЛС | `123-456-789 01` с контрольной суммой или 11 цифр после слова «СНИЛС» |
| `PASPORT` | серия и номер паспорта, код подразделения | рядом со словами «паспорт», «серия», «код подразделения» |
| `KARTA` | номер карты | 16–19 цифр, проверка Луна |
| `SCHET` | расчётный и корреспондентский счёт | 20 цифр |
| `DR` | дата рождения | рядом с «дата рождения», «г.р.» и т.п. |
| `ADRES` | улица, дом, квартира | «ул. Ленина, д. 5, кв. 12» (город остаётся) |

Метка — это HMAC от значения с секретом `PD_SECRET`, поэтому одно и то же значение получает одну и ту же метку во всех запросах чата, а прокси ничего не хранит. Модели добавляется короткая служебная пометка о метках (`PD_HINT=0` отключает).

Не прячется: названия организаций, произвольные имена без отчества («Сергей»), адреса без улицы и дома, содержимое картинок и PDF, которые модель получает как файлы (текст, извлечённый DEEIX, маскируется). Рассуждения модели показываются с метками.

## Настройки (`/opt/deeix-ru/pd-mask.env`)

```
PD_SECRET=<openssl rand -hex 16>
PD_ROUTES=ds=https://api.deepseek.com;zai=https://api.z.ai
```

- `PD_ROUTES`: маршруты `имя=https://хост`, через `;`. Адрес источника в DEEIX `https://api.deepseek.com/anthropic` становится `http://deeix-pd-mask:8090/ds/anthropic`: хост заменяется на прокси и имя маршрута, путь остаётся. Слово `always` после адреса (`agg-all=https://… always`) маскирует каждый запрос маршрута без флага (для моделей задач: названия чатов, сжатие истории).
- `PD_TYPES`: какие типы прятать, через запятую (по умолчанию все).
- `PD_REJECT_FILES=1`: не отправлять запрос с маскировкой, если в нём есть картинки или файлы.
- `PD_HINT=0`: не добавлять служебную пометку.

Поддерживаются протоколы OpenAI Chat Completions и Anthropic Messages, с потоком и без. Запрос с флагом на другой протокол (например, OpenAI Responses) не отправляется, прокси отвечает ошибкой. Без флага запросы проходят без изменений, байт в байт.

## Переключатель в DEEIX

В JSON возможностей модели (Админка → Модели → модель → Возможности):

```json
"controls": [
  {"id": "pd_mask", "type": "toggle", "label": "Маскировка ПД",
   "description": "Прятать ФИО, ИНН, телефоны и другие ПД перед отправкой модели",
   "icon": "shield", "placement": "menu",
   "on": {"patch": {"deeix_pd_mask": true}}, "off": {}}
]
```

Переключатель появляется в панели «⋯» (Параметры чата), его можно закрепить в поле ввода. Источник этой модели должен идти через прокси, иначе флаг уйдёт провайдеру, а данные не замаскируются.

## Просмотр перед отправкой

С патчем `pd-preview` у переключателя появляется кнопка «Просмотр»: перед отправкой DEEIX показывает сообщение и текст вложений так, как их получит модель. Для этого DEEIX обращается к прокси по `POST /preview` (`{"texts":[{"id","text"}],"keep":[],"hide":[]}` → замаскированные тексты, список замен и подозрительные слова). В окне можно оставить значение как есть («Прятать» выкл.) или спрятать ещё слово; выбор приходит в запросе как `"deeix_pd_mask_rules": {"keep": [...], "hide": [...]}`, прокси применяет его и удаляет ключ. Добавленные вручную слова получают метку `[FIO_…]` (с заглавной) или `[PD_…]`, другие падежи слова прячутся тоже.

## Проверка без сети

```
echo "Иванов Иван Иванович, ИНН 500100732259" | docker run --rm -i -e PD_SECRET=test-secret-0123456 deeix-pd-mask:latest mask
```

Журнал (`docker logs deeix-pd-mask`) пишет только число замен по типам, сами значения не пишутся.
